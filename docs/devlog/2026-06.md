### Decisões Técnicas

- **Abordagem A** mantida para nomes: internos (`[lib] librustdesk`, binário `rustdesk`, packer `rustdesk-portable-packer`) ficam upstream — o Dart abre a lib FFI por nome fixo e vários pontos assumem o processo `rustdesk`; branding só nas superfícies visíveis (winres, .desktop, unit systemd, nome do pacote/artefato).
- **Toolchain pinada é requisito**, não sugestão: Flutter **3.24.5** (tag + patch), Rust 1.75, vcpkg com libvpx/libyuv/opus/aom. SDK global atualizado (3.44 / GCC 15) quebra o build — documentado no README.
- `apt` não reinstala a mesma versão: rebuilds sem bump exigem `--reinstall`.
